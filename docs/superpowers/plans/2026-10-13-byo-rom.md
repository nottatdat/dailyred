# Bring-your-own-ROM Daily Red Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve Daily Red publicly at https://red.tatd.at with no ROM on the server: players load their own FireRed ROM and the site patches it into the game in the browser.

**Architecture:** The build still compiles pret/pokefirered + `patches/` into `pokefirered_modern.gba`, then `make-patch.sh` diffs it against vanilla FireRed 1.0 and Rev 1 into BPS patches. In the browser, `rom-store.js` identifies (SHA-1) and remembers (IndexedDB) the player's ROM, `bps.js` applies the matching patch, and `game-files.js` hands the result to the unchanged seed-injection/emulator flow. The static `web/` is served by `serve.mjs` on fountain behind a named Cloudflare tunnel.

**Tech Stack:** Bash, GNU make, xPack arm-none-eabi-gcc 14.2.1, pret/agbcc, Flips (BPS creation), vanilla ES modules, Node 24 (`node:test`), playwright-core 1.56.1 + Playwright's Chromium, systemd user units, cloudflared 2026.9.3.

**Spec:** `docs/superpowers/specs/2026-10-13-byo-rom-design.md`

## Global Constraints

- The deployed `web/` contains no `*.gba`, `*.gba.gz` and no `red.png`.
- Accepted base ROMs, by SHA-1 only: FireRed 1.0 `41cb23d8dccc8ebd7c649cd8fbb58eeace6e2fdc`, FireRed Rev 1 `dd5945db9b930750cb39d00c84da8571feebf417`. Size 16,777,216 bytes.
- Rejection message (exact): `This isn't English Pokémon FireRed (1.0 or Rev 1).`
- pret/pokefirered pinned at `037335f4c725d7c9aecdac87066f2002b4bd7e14`; toolchain xPack `14.2.1-1.1`.
- The player's ROM never leaves the browser; no server code beyond static file serving.
- IndexedDB database `dailyred`, object store `rom`, key `firered`; the **original** ROM is stored, never the patched one.
- `loadGameFiles(onProgress)` keeps its signature and returns `{ rom: Uint8Array, coreJs: Blob, coreWasm: Blob }`.
- Base ROM for building patches comes from env `FIRERED_REV1` (on magnus: `/home/dat/src/g16/roms/Pokemon - FireRed Version (USA, Europe) (Rev 1).gba`).
- Hosting: fountain, `127.0.0.1:8030`, tunnel name `dailyred`, hostname `red.tatd.at`, units `dailyred.service` + `red-tunnel.service`.

## Review Focus

1. A correct ROM with a different file name/extension (`.bin`, `firered.GBA`) → accepted (identification is by bytes, never by name). Test in Task 4.
2. A huge or tiny non-ROM file (e.g. a 200 MB video) → rejected quickly by size, without hashing. Test in Task 4.
3. IndexedDB unavailable or throwing (private mode, blocked storage) → the ROM still works for the current visit. Test in Task 5 (site test with IndexedDB disabled).
4. Site redeployed with new patches while a player has an old stored ROM → still plays without re-upload (original stored). Test in Task 4 (`loadRom` returns original bytes) and Task 3 (patch applied to the same base).
5. Pressing Play/Try again with no ROM, or "Forget my ROM" while on the title → the ROM prompt appears, never a broken download error. Test in Task 5.

#!/usr/bin/env bash
# Installs everything needed to build Daily Red and its patches on Linux x86_64,
# into ./.toolchain (no sudo). Needs: curl, git, make, a host C/C++ compiler,
# and libpng headers (the system libpng is used for pokefirered's gbagfx).
#
#   - xPack GNU Arm Embedded GCC (same pinned version as setup-macos.sh)
#   - pret/agbcc, for the byte-exact vanilla FireRed 1.0 build (make-patch.sh)
#   - Flips, to create the BPS patches
#
# Re-running is safe: finished steps are skipped.
set -euo pipefail

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
TC="$ROOT/.toolchain"
mkdir -p "$TC/downloads" "$TC/bin"

GCC_VER="14.2.1-1.1"
AGBCC_COMMIT="da598c1d918402c42c0c0d7128ba14567f3175e9"
FLIPS_COMMIT="ff216a75df0987047a67d7923567dc4482ce07ac"

[ "$(uname -m)" = x86_64 ] || { echo "Unsupported CPU: $(uname -m)"; exit 1; }
pkg-config --exists libpng || { echo "libpng development files are required (e.g. pacman -S libpng)"; exit 1; }

# --- arm-none-eabi GCC --------------------------------------------------------
GCC_NAME="xpack-arm-none-eabi-gcc-$GCC_VER"
if [ ! -x "$TC/arm-none-eabi/bin/arm-none-eabi-gcc" ]; then
  tarball="$GCC_NAME-linux-x64.tar.gz"
  url="https://github.com/xpack-dev-tools/arm-none-eabi-gcc-xpack/releases/download/v$GCC_VER/$tarball"
  echo ">> Downloading $tarball"
  curl -fL --retry 3 -o "$TC/downloads/$tarball" "$url"
  curl -fsL -o "$TC/downloads/$tarball.sha" "$url.sha"
  expected="$(awk '{print $1}' "$TC/downloads/$tarball.sha")"
  actual="$(sha256sum "$TC/downloads/$tarball" | awk '{print $1}')"
  [ "$expected" = "$actual" ] || { echo "Checksum mismatch for $tarball"; exit 1; }
  tar -xzf "$TC/downloads/$tarball" -C "$TC"
  rm -f "$TC/arm-none-eabi" && ln -s "$GCC_NAME" "$TC/arm-none-eabi"
  rm -f "$TC/downloads/$tarball"
fi
"$TC/arm-none-eabi/bin/arm-none-eabi-gcc" --version | head -1
echo 'int f(void){return 0;}' | "$TC/arm-none-eabi/bin/arm-none-eabi-gcc" -x c -c -o /dev/null -

# --- agbcc (pret's GCC 2.95 fork, for the matching vanilla build) ------------
if [ ! -x "$TC/agbcc/bin/agbcc" ]; then
  src="$TC/downloads/agbcc"
  rm -rf "$src"
  git init -q "$src"
  git -C "$src" fetch -q --depth 1 https://github.com/pret/agbcc.git "$AGBCC_COMMIT"
  git -C "$src" checkout -q FETCH_HEAD
  (cd "$src" && ./build.sh)
  mkdir -p "$TC/agbcc"
  cp -r "$src"/agbcc "$src"/old_agbcc "$src"/agbcc_arm "$TC/agbcc/" 2>/dev/null || true
  # install.sh copies into <pokefirered>/tools/agbcc; make-patch.sh runs it against
  # the vanilla checkout, so keep the built tree.
  rm -rf "$TC/agbcc-src" && mv "$src" "$TC/agbcc-src"
  mkdir -p "$TC/agbcc/bin" && ln -sf "$TC/agbcc-src/agbcc" "$TC/agbcc/bin/agbcc"
fi
echo ">> agbcc: $TC/agbcc-src"

# --- Flips ---------------------------------------------------------------------
if [ ! -x "$TC/bin/flips" ]; then
  src="$TC/downloads/flips"
  rm -rf "$src"
  git init -q "$src"
  git -C "$src" fetch -q --depth 1 https://github.com/Alcaro/Flips.git "$FLIPS_COMMIT"
  git -C "$src" checkout -q FETCH_HEAD
  make -C "$src" TARGET=cli
  cp "$src/flips" "$TC/bin/flips"
fi
"$TC/bin/flips" --version 2>/dev/null | head -1 || true

echo "Toolchain ready. Build with: scripts/build-rom.sh && scripts/make-patch.sh"

```js
// Applies a BPS patch to a ROM (format: byuu's BPS, as written by Flips).
// The site ships Daily Red only as patches against the player's own FireRed.

const CRC_TABLE = (() => {
  const table = new Uint32Array(256);
  for (let n = 0; n < 256; n++) {
    let c = n;
    for (let k = 0; k < 8; k++) c = c & 1 ? 0xEDB88320 ^ (c >>> 1) : c >>> 1;
    table[n] = c >>> 0;
  }
  return table;
})();

export function crc32(bytes) {
  let crc = 0xFFFFFFFF;
  for (let i = 0; i < bytes.length; i++) crc = CRC_TABLE[(crc ^ bytes[i]) & 0xFF] ^ (crc >>> 8);
  return (crc ^ 0xFFFFFFFF) >>> 0;
}

function fail(message) {
  throw new Error(`Patch failed: ${message}`);
}

export function applyBps(source, patch) {
  if (patch.length < 19 || String.fromCharCode(...patch.subarray(0, 4)) !== 'BPS1') fail('not a BPS patch');
  const footer = new DataView(patch.buffer, patch.byteOffset + patch.length - 12, 12);
  const sourceCrc = footer.getUint32(0, true);
  const targetCrc = footer.getUint32(4, true);
  const patchCrc = footer.getUint32(8, true);
  if (crc32(patch.subarray(0, patch.length - 4)) !== patchCrc) fail('the patch file is damaged');
  if (crc32(source) !== sourceCrc) fail("the ROM doesn't match this patch");

  const end = patch.length - 12;
  let pos = 4;
  // Variable-length numbers; plain arithmetic because values can exceed 2^31.
  const number = () => {
    let value = 0;
    let shift = 1;
    for (;;) {
      if (pos >= end) fail('the patch file is damaged');
      const x = patch[pos++];
      value += (x & 0x7F) * shift;
      if (x & 0x80) return value;
      shift *= 128;
      value += shift;
    }
  };
  const signed = () => {
    const n = number();
    return (n % 2 ? -1 : 1) * Math.floor(n / 2);
  };

  const sourceSize = number();
  const targetSize = number();
  pos += number(); // metadata
  if (sourceSize !== source.length) fail("the ROM doesn't match this patch");

  const target = new Uint8Array(targetSize);
  let out = 0;
  let sourceRel = 0;
  let targetRel = 0;
  while (pos < end) {
    const data = number();
    const action = data % 4;
    const length = Math.floor(data / 4) + 1;
    if (out + length > targetSize) fail('the patch file is damaged');
    if (action === 0) { // SourceRead
      target.set(source.subarray(out, out + length), out);
    } else if (action === 1) { // TargetRead
      if (pos + length > end) fail('the patch file is damaged');
      target.set(patch.subarray(pos, pos + length), out);
      pos += length;
    } else if (action === 2) { // SourceCopy
      sourceRel += signed();
      if (sourceRel < 0 || sourceRel + length > source.length) fail('the patch file is damaged');
      target.set(source.subarray(sourceRel, sourceRel + length), out);
      sourceRel += length;
    } else { // TargetCopy: may overlap the bytes being written, so copy one at a time
      targetRel += signed();
      if (targetRel < 0 || targetRel >= out) fail('the patch file is damaged');
      for (let i = 0; i < length; i++) target[out + i] = target[targetRel + i];
      targetRel += length;
    }
    out += length;
  }
  if (out !== targetSize || crc32(target) !== targetCrc) fail("the result isn't the expected game");
  return target;
}
```

```bash
#!/usr/bin/env bash
# Turns the built Daily Red ROM into BPS patches against vanilla Pokémon FireRed,
# so the website never serves the game itself: players load their own ROM.
#
#   FIRERED_REV1=/path/to/firered-rev1.gba scripts/make-patch.sh
#
# FireRed 1.0 is built byte-exact from the same pinned pret/pokefirered commit
# with agbcc (no dump needed); Rev 1 comes from FIRERED_REV1. Both are checked
# against their known SHA-1 before any patch is made.
set -euo pipefail

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
TC="$ROOT/.toolchain"
OUT="$ROOT/web/game"
BUILT="$ROOT/pokefirered/pokefirered_modern.gba"
SHA_10="41cb23d8dccc8ebd7c649cd8fbb58eeace6e2fdc"
SHA_REV1="dd5945db9b930750cb39d00c84da8571feebf417"
PRET_COMMIT="$(sed -n 's/^PRET_COMMIT="\(.*\)"/\1/p' "$ROOT/scripts/get-pokefirered.sh")"
JOBS="$(nproc 2>/dev/null || sysctl -n hw.ncpu)"

sha1() { sha1sum "$1" 2>/dev/null | cut -d' ' -f1 || shasum "$1" | cut -d' ' -f1; }
need() { [ -e "$1" ] || { echo "$2"; exit 1; }; }

need "$TC/bin/flips" "Flips missing. Run scripts/setup-linux.sh first."
need "$BUILT" "Daily Red ROM missing. Run scripts/build-rom.sh first."
[ -n "${FIRERED_REV1:-}" ] || { echo "Set FIRERED_REV1 to your FireRed (USA, Europe) Rev 1 ROM."; exit 1; }
[ "$(sha1 "$FIRERED_REV1")" = "$SHA_REV1" ] || { echo "FIRERED_REV1 isn't a clean FireRed Rev 1 (SHA-1 mismatch)."; exit 1; }

# --- Vanilla FireRed 1.0, built byte-exact ------------------------------------
VAN="$TC/vanilla"
if [ ! -f "$VAN/pokefirered.gba" ] || [ "$(sha1 "$VAN/pokefirered.gba")" != "$SHA_10" ]; then
  need "$TC/agbcc-src/install.sh" "agbcc missing. Run scripts/setup-linux.sh first."
  rm -rf "$VAN/src"
  git init -q "$VAN/src"
  git -C "$VAN/src" fetch -q --depth 1 https://github.com/pret/pokefirered.git "$PRET_COMMIT"
  git -C "$VAN/src" checkout -q FETCH_HEAD
  (cd "$TC/agbcc-src" && ./install.sh "$VAN/src")
  PATH="$TC/arm-none-eabi/bin:$PATH" make -C "$VAN/src" -j"$JOBS" firered
  cp "$VAN/src/pokefirered.gba" "$VAN/pokefirered.gba"
fi
[ "$(sha1 "$VAN/pokefirered.gba")" = "$SHA_10" ] || { echo "Vanilla 1.0 build isn't byte-exact (SHA-1 mismatch)."; exit 1; }

# --- Patches -----------------------------------------------------------------
mkdir -p "$OUT"
rm -f "$OUT"/*.gba "$OUT"/*.gba.gz "$OUT"/red.png "$OUT"/*.bps
"$TC/bin/flips" --create --bps-delta "$VAN/pokefirered.gba" "$BUILT" "$OUT/dailyred-firered-1.0.bps"
"$TC/bin/flips" --create --bps-delta "$FIRERED_REV1" "$BUILT" "$OUT/dailyred-firered-rev1.bps"

size() { wc -c < "$1" | tr -d ' '; }
cat > "$OUT/patches.json" <<EOF
{
  "1.0": { "sha1": "$SHA_10", "patch": "dailyred-firered-1.0.bps", "bytes": $(size "$OUT/dailyred-firered-1.0.bps") },
  "rev1": { "sha1": "$SHA_REV1", "patch": "dailyred-firered-rev1.bps", "bytes": $(size "$OUT/dailyred-firered-rev1.bps") }
}
EOF
echo
ls -l "$OUT"
```

```js
// The player's own Pokémon FireRed ROM: recognising it, and remembering it in
// this browser (IndexedDB) so it's only loaded once. The original ROM is stored,
// not the patched game, so a site update never needs a new upload. Nothing here
// ever sends the ROM anywhere.

export const ROM_SIZE = 16 * 1024 * 1024;
export const FIRERED_VERSIONS = {
  '41cb23d8dccc8ebd7c649cd8fbb58eeace6e2fdc': '1.0',
  dd5945db9b930750cb39d00c84da8571feebf417: 'rev1',
};
export const WRONG_ROM_MESSAGE = "This isn't English Pokémon FireRed (1.0 or Rev 1).";

export async function identifyRom(bytes) {
  if (bytes.length !== ROM_SIZE) return null;
  const digest = new Uint8Array(await crypto.subtle.digest('SHA-1', bytes));
  const hex = Array.from(digest, (b) => b.toString(16).padStart(2, '0')).join('');
  return FIRERED_VERSIONS[hex] ?? null;
}

const DB = 'dailyred';
const STORE = 'rom';
const KEY = 'firered';
let memory = null; // fallback when IndexedDB is unavailable (e.g. private mode)

function request(mode, run) {
  return new Promise((resolve, reject) => {
    if (typeof indexedDB === 'undefined') { reject(new Error('IndexedDB unavailable')); return; }
    const open = indexedDB.open(DB, 1);
    open.onupgradeneeded = () => open.result.createObjectStore(STORE);
    open.onerror = () => reject(open.error);
    open.onsuccess = () => {
      const db = open.result;
      const req = run(db.transaction(STORE, mode).objectStore(STORE));
      req.onsuccess = () => { db.close(); resolve(req.result); };
      req.onerror = () => { db.close(); reject(req.error); };
    };
  });
}

export async function saveRom(bytes) {
  memory = bytes;
  try {
    await request('readwrite', (store) => store.put(bytes, KEY));
  } catch (err) {
    console.warn('ROM kept for this visit only:', err.message);
  }
}

export async function loadRom() {
  if (memory) return memory;
  try {
    const stored = await request('readonly', (store) => store.get(KEY));
    memory = stored ? new Uint8Array(stored) : null;
  } catch {
    memory = null;
  }
  return memory;
}

export async function forgetRom() {
  memory = null;
  try {
    await request('readwrite', (store) => store.delete(KEY));
  } catch { /* nothing stored */ }
}
```

```js
// Builds the game in the browser: the player's own FireRed ROM (rom-store.js)
// plus this site's Daily Red patch (bps.js). The emulator core is downloaded
// once per visit and kept in memory, so a new run only restarts the emulator.
import { applyBps } from './bps.js';
import { identifyRom, loadRom, forgetRom, WRONG_ROM_MESSAGE } from './rom-store.js';

export class NoRomError extends Error {}

const CORE = {
  coreJs: 'vendor/mgba_libretro.js',
  coreWasm: 'vendor/mgba_libretro.wasm',
};

let cached = null;

// onProgress(loadedBytes, totalBytes) — totalBytes is 0 when unknown.
export function loadGameFiles(onProgress = () => {}) {
  cached ??= build(onProgress).catch((err) => {
    cached = null; // allow a retry
    throw err;
  });
  return cached;
}

// After the player loads or forgets a ROM.
export function resetGameFiles() {
  cached = null;
}

async function fetchOk(url) {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`Couldn't download ${url} (HTTP ${res.status}).`);
  return res;
}

async function build(onProgress) {
  const base = await loadRom();
  if (!base) throw new NoRomError('Load your Pokémon FireRed ROM first.');
  const version = await identifyRom(base);
  if (!version) {
    await forgetRom();
    throw new NoRomError(WRONG_ROM_MESSAGE);
  }
  const manifest = await (await fetchOk('game/patches.json')).json();
  const entry = manifest[version];
  if (!entry) throw new Error(`This site has no patch for FireRed ${version}.`);

  const urls = [`game/${entry.patch}`, CORE.coreJs, CORE.coreWasm];
  const responses = await Promise.all(urls.map(fetchOk));
  // Content-Length is only meaningful when the host didn't re-encode the file.
  const sizes = responses.map((r) => (r.headers.get('Content-Encoding') ? 0 : Number(r.headers.get('Content-Length')) || 0));
  const total = sizes.every(Boolean) ? sizes.reduce((a, b) => a + b, 0) : 0;
  let loaded = 0;
  const report = (n) => { loaded += n; onProgress(loaded, total); };

  const [patch, coreJs, coreWasm] = await Promise.all(responses.map((res) => readAll(res, report)));
  return {
    rom: applyBps(base, patch),
    coreJs: new Blob([coreJs], { type: 'text/javascript' }),
    coreWasm: new Blob([coreWasm], { type: 'application/wasm' }),
  };
}

async function readAll(res, report) {
  const reader = res.body.getReader();
  const chunks = [];
  let size = 0;
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    chunks.push(value);
    size += value.length;
    report(value.length);
  }
  const bytes = new Uint8Array(size);
  let offset = 0;
  for (const chunk of chunks) {
    bytes.set(chunk, offset);
    offset += chunk.length;
  }
  return bytes;
}
```
